# Recetas Four For Love

Este proyecto nace de la idea de tener siempre accesibles las recetas que más nos gustan en casa, pero también de que cualquier persona interesada, pueda crear su sesión y tener sus propias recetas siempre a mano.

## Tecnologías utilizadas

A nivel de frontend, se ha utilizado HTML5 y Java Script Vanilla pero con el Framework de React. La maquetación se ha realizado con CSS.

Con respecto a backend, hemos configurado una base de datos relacional a través de MySQL Workbench y empleado Node JS y Express JS en el código. Hemos hecho uso de CORS para que se puedan hacer peticiones a nuestra API desde cualquier lugar y AuthProvider para la autenticación de usuarios/as.

## Estrategia de Despliegue

Hemos hecho uso de plataformas gratuitas para desplegar el proyecto. La base de datos la hemos alojado en TiDB Cloud, como servidor hemos utilizado render.com y por último, el despligue de frontend lo hemos gestionado con Git Hub Pages.

Mencionar que Git Hub ha sido nuestro gestor de versiones.

# Four For Love Recipes

This project was born from the idea of ​​always having the recipes that we like the most at home accessible, but also that anyone interested can create their session and have their own recipes always at hand.

## Technologies used

At the frontend level, HTML5 and Vanilla Java Script have been used but with the React Framework. The layout has been done with CSS. Regarding backend, we have set up a relational database through MySQL Workbench and used Node JS and Express JS in the code. We have made use of CORS so that requests can be made to our API from anywhere and AuthProvider for user authentication.

## Deployment Strategy

We have made use of free platforms to deploy the project. We have hosted the database in TiDB Cloud, as a server we have used render.com and finally, we have managed the frontend deployment with Git Hub Pages.

Mention that Git Hub has been our version manager.
